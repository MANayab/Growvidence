# ADR-0003: Project name

- **Status:** Working name only — clearance not performed
- **Date:** 2026-11-18

## Context

The maintainer selected “Growvidence” as the working project name for an evidence-based learning and skill-tracking product.

## Decision

Use **Growvidence** in repository documentation and internal discussion as a provisional name.

## Consequences and limitations

- No trademark search, legal opinion, domain availability check, company-name check, or app-store search is recorded here.
- Do not purchase a domain, register a mark, publish listings, or claim legal exclusivity as part of this phase.
- Before public commercial launch, perform appropriate name clearance in relevant jurisdictions and product categories.
- Candidate sub-brand labels (Learn, Skills, Proof, Insights, Teams) remain unapproved.

## Review trigger

Revisit before domain purchase, formal branding, company formation, or app-store publication.
