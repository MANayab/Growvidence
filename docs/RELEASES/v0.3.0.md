# Growvidence v0.3.0 — Learning Journal and AI-use Disclosure (Draft)

**Status:** Draft release notes for maintainer review. Slice 3 is not merged or released.

## Proposed highlights
- Record learning journal entries with title, learned, blocked, next, confidence, time spent, optional track/task links and a local date.
- Canonical `date` field is date-only `YYYY-MM-DD`, never converted through UTC; the earlier `attemptedAt` field is removed.
- Explicit AI-use disclosure: assisted, unassisted, partially assisted, unknown and not recorded (default).
- Filter entries by track, date range and disclosure mode; view counts and minutes separately for all five states.
- Soft and permanent deletion for journal records.
- IndexedDB schema version 4 with migration path and abort-safety coverage.

## Verification required before release
- Maintainer's local `npm ci`, formatting, diagnostics, lint, tests, build, static verification, bundle-size and dependency audits.
- CI must pass on the exact PR head.
- Manual browser testing of responsive layout, keyboard/focus behavior, date-only stability, delete confirmation, filters, summaries, AI disclosure and migration recovery.
- Review release scope and documentation consistency.

## Limitations
- No competency assessment, evidence manager, backup/import/export or dashboard in Slice 3.
- Journal entries are local browser data, not cloud-synced or a backup.
- No tag or GitHub Release is created by this draft.
- License remains undecided.
